# Legnext готов к работе

Плагин установлен. Проверьте, что ключ принят — попросите агента в **новой сессии**:

> Проверь баланс Legnext инструментом `mj_balance`. Платных задач не создавай.

Эта проверка бесплатна. Если ответ — ошибка 401, ключ не принят: перевыпустите его в кабинете Legnext и впишите в файл, который покажет `hermes config env-path`.

Если ключ при установке был пропущен, добавьте строку `LEGNEXT_API_KEY=<ключ>` в тот же файл. Значение ключа не вводите в чат агента.

## Первая генерация

Стоит около $0.08 за сетку из четырёх картинок:

> Создай через `mj_imagine`: «вечерний вокзал под дождём, акварель, мягкий свет --ar 16:9». Дождись готовности и покажи локальные пути PNG.

Готовые PNG сохраняются локально, по умолчанию в `<HERMES_HOME>/legnext-output`.

## Что полезно знать сразу

- Каждая генерация, upscale, variation и reroll списывают деньги. `mj_balance` и чтение статуса задачи — бесплатны.
- Без явного `--v` в запросе используется версия `8.2` (настройка `default_version`). Если очистить настройку, Legnext вернётся к v7.
- Картинки в сетке нумеруются с нуля: первая — `image_no=0`, четвёртая — `image_no=3`.
- Действия над готовой задачей доступны трое суток с её создания.
- Таймаут ожидания не отменяет задачу на сервере. Вернитесь к ней через `mj_job` по сохранённому `job_id`, не отправляйте генерацию повторно — это новое списание.
